# Hoja para E6a y E10a: lectura visual con renders

El prerregistro está en [`ensayos.md`](ensayos.md#e6a-y-e10a--lectura-visual-con-renders-antes-de-las-maquetas--prerregistro). Las imágenes están en [`../05_consolidar/renders/`](../05_consolidar/renders/) y salen del modelo de Blender, con la misma cámara y la misma luz.

## Cómo se hace

1. Muéstrale cada imagen a **5 personas**, una por una, sin decir de qué concurso es ni qué se busca.
2. Haz **solo la pregunta escrita** y anota la respuesta **con sus palabras**, sin resumirla.
3. Recién después clasifica cada respuesta. Así no hay sesgo al escuchar.

## E6a: la unión

Muestra primero `nodo_B2.png` (solo madera) y después `nodo_AB.png` (con collar de piedra). Pregunta: **«¿Qué hace cada pieza de esta unión?»**

| Persona | Respuesta sobre la piedra (literal) | Clasificación: ADORNO / TRABA-SUJETA / OTRA |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |
| 5 | | |

**Regla prerregistrada**:
- 3 o más ADORNO → el collar cambia de forma o tamaño, o AB baja frente a B3 o B2.
- 3 o más TRABA-SUJETA → AB pasa a la maqueta física (E6).
