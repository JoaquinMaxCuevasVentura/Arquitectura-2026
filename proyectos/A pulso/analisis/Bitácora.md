# Bitácora

Una entrada por semana, el mismo día. Incluye la hora semanal de **releer los ensayos** que pide la propuesta.

## Tope de herramientas

La propuesta fija que el software no supere el **20 %** del tiempo (≈48 de 240 horas). Si la columna «Herramientas» acumulada pasa ese número, el instrumento se está comiendo el proyecto: se para y se vuelve al banco.

| Semana | Fase | Ensayos (h) | Lectura y análisis (h) | Tipografía (h) | Herramientas (h) | Edición y difusión (h) | Total (h) | Herramientas acumuladas / total |
|---|---|---|---|---|---|---|---|---|
| S01 | F0 | | | | | | | |
