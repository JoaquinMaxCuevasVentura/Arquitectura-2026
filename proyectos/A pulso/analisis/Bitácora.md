# Bitácora

Una entrada por semana, el mismo día. Incluye la hora semanal de **releer los ensayos** que pide la propuesta.

## Tope de herramientas

La propuesta asigna a las herramientas digitales un 8 % del tiempo (≈ 20 de 240 horas), porque ya están construidas; el **tope** es el 20 % (≈ 48 horas). Si la columna «Herramientas» acumulada pasa ese número, el instrumento se está comiendo el proyecto: se para y se vuelve al banco.

| Semana | Fase | Ensayos (h) | Archivo y entrevistas (h) | Lectura y análisis (h) | Tipografía (h) | Herramientas (h) | Edición y difusión (h) | Total (h) | Herramientas acumuladas / total |
|---|---|---|---|---|---|---|---|---|---|
| S01 | F0 | | | | | | | | |
