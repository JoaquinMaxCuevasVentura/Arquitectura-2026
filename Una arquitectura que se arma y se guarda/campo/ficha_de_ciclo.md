# Ficha de ciclo (plantilla)

Copiar una ficha por ciclo en `campo/privado/` (no se sube al repositorio). Al terminar el día, pasar la lista de operaciones a `registro_de_operaciones.csv`, solo con códigos.

## Datos

| Campo | Valor |
|---|---|
| Puesto | P_ |
| Ciclo | C_ |
| Fecha y día de la semana | |
| Tipo de día | común / feria / otro: |
| Clima | sol / nubes / lluvia / granizo / viento; temperatura aproximada |
| Consentimiento | oral, fecha: ___ ; no registrar: ___ |
| Personas | R (responsable); A1, A2… (quienes ayudan; edad aproximada si es relevante) |
| Montaje | llegada del primer bulto ___ ; puesto listo para vender ___ |
| Desmontaje | inicio ___ ; salida del último bulto ___ |
| Fotos | intervalo ___ s; punto fijo: ___ ; carpeta: ___ |

## Croquis

- Planta del lugar vacío, con los apoyos prestados y las huellas fijas.
- Planta del puesto armado, con cotas.
- Lo que se queda en la calle de noche, si algo se queda.
